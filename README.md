# Cyrus Val'Dira build compendium

A Pathfinder 2e build reference for Cyrus Val'Dira, a Laughing Shadow magus, with an offline rules glossary.

Open the GitHub Pages address in Safari on iPhone, choose an icon on the Overview page, then use Share > Add to Home Screen. It works offline after the first visit.

Rules text is from Archives of Nethys under the ORC and OGL licences. Icons are from game-icons.net (CC BY 3.0).
